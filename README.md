# Aurix Data Pipelines

Data pipeline infrastructure for the Aurix platform.

## Overview

ETL and streaming pipelines that process financial transaction data, aggregate metrics, and feed data into the analytics layer.

## Tech Stack

- Apache Spark / PySpark
- Apache Kafka
- Airflow (workflow orchestration)
- Python
